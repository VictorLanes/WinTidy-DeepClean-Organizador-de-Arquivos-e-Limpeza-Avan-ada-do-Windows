# WinTidy-DeepClean-Organizador-de-Arquivos-e-Limpeza-Avan-ada-do-Windows
Ferramenta desktop em Python para Windows que organiza pastas por categorias com backup automático (.zip) e realiza limpeza profunda de temporários e caches do sistema (Temp, Prefetch, DNS, DirectX e DISM). Sem dependências externas e com elevação automática de administrador.
